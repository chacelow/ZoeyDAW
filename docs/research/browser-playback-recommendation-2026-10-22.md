# Browser 与时间线播放的选型建议

2026-10-22。目标与验收范围已按用户“没问题就 goal set”的指令设定。具体音频库仍是候选，不因设目标自动批准依赖、商业许可、配置修改或远程操作。没有测得“优于 Live”的性能或音质成绩。

## 推荐先证明什么

不迁移现有 React、Tauri 和 Canvas。把 Browser、试听、音频素材、编排播放作为一个完整工作流设计。首批 macOS 和 Windows、本地音频、工程 BPM 同步且保持音高。范围小于整台 DAW，但这一条工作流不能用粗糙替代品交付。

体验优先在这里改变了实现顺序。不能交付只会原速发声的播放器，然后把正确同步、试听一致性、取消和缺失素材处理推成可有可无的优化。

## 交付目标

在保留现有 UI、设置、主题与语言交互的前提下，完成 macOS 与 Windows 桌面的真实本地音频 Browser、试听、拖入编排、波形、保持音高的 BPM 同步及多轨播放。以 Live 的实际行为作为基线，逐项说明保留、改进或有理由不同的交互；不得以原型占位、静默降级或依赖缺口缩减目标。

功能完成必须满足本文验收场景，包含本地工程保存、关闭重开、媒体收集与缺失素材恢复。只写 localStorage 快照不满足真实媒体工程的保存条件。首批格式为 WAV、AIFF、FLAC、MP3，具体编码、位深和声道矩阵由可重复语料验证，不把扩展名当完整兼容证明。

“更好”的比较限定在本工作流，不要求整体超过 Live 全部功能。先冻结素材、平台、设备、缓冲、对照步骤和测量口径，再锁定体验、声音、内存与实时性能的通过阈值，之后不能按实现成绩降低标准。选定改进项必须有可重复的优势证据，其他关键路径不得出现未接受的退化；测不出优势时如实报告，不能仅凭功能可用宣称达成更优目标。

## 执行前补齐的验证条件

1. 建立合法可用的对照语料，覆盖 one-shot、整拍与非整拍循环、自由速度人声、完整混音、长压缩文件、半倍/双倍 BPM、错误首拍、坏文件、同源多位置并播。记录来源与校验和，用户素材未经许可不上传或写进仓库。
2. 明确 macOS 和 Windows 的实际机器、系统、CPU 架构、音频设备及驱动矩阵。设备不在场时不能用交叉编译代替真机通过，缺少的验收保持未通过。
3. 对完整引擎与模块化方案做相同条件的可撤销验证，再冻结核心选型。无需先购买 SDK，也不因某个候选不可得就默认低质量替代通过。
4. 在正式接入工程存储前完成媒体默认引用或收集的推荐，依据便携、安全、空间和响应时间，不重复要求用户决定实现细节。涉及不可逆产品取舍或费用时用 ask 集中确认。
5. 对 Browser、后台任务、媒体源、工程 Clip、试听与编排播放确定单一状态 owner、取消与资源释放协议。缓存空间不足、权限拒绝、源文件改变和设备丢失必须有真实状态及恢复，不返回虚假成功。

这些是目标内的前置工作，不是要求用户现在提供全部细节。执行中按仓库授权边界推进，不启动或重启用户的 tauri:dev，不自动提交、发布或购买许可。

## 当前证据支持的核心路线

| 位置 | 推荐或候选 | 理由与当前限制 |
| --- | --- | --- |
| UI | 保留现有 React、Tauri、Canvas | 尊重用户明确“不迁移”。UI 和音频分别验证，不用整体框架重写代替 profiling。 |
| 原生音频职责 | 原生音频设备时钟拥有播放进度，非实时线程负责媒体准备 | Ardour、Tracktion 已有成熟例子。现有 adapter 的事务、生命周期与遥测可作为接入边界，但 mock 不证明最终契约正确。 |
| 整体引擎 | Tracktion Engine 进入可行性验证候选 | Context7 官方资料确认独立 Edit、TransportControl 和实时拉伸能力。不是已批准替换；需要比较 JUCE/C++ 集成、商业许可和长压缩媒体内存路径。 |
| Rust 模块化路线 | CPAL、Symphonia、Rubato 进入输出、解码与采样率转换短名单 | 三者不组成完整 DAW。CPAL 当前 WASAPI 路径为共享模式，ASIO 需正式处理 SDK 和驱动；格式按实际 features 与编码语料验收。 |
| Futureboard、SoundCraft | 局部参考，不整体接管 | 前者有真实流播和取消，也有依赖耦合与长文件限制；后者自身承认 RAM 和 fidelity 缺口。开源不等于稳定 SDK。 |
| 时间拉伸 | 比较 Signalsmith Stretch、Rubber Band，商业 élastique 作为可获得时的对照 | 不自研保持音高算法。输入前瞻、输出延迟、seek priming、立体声相干都要测。现有 Signalsmith Rust wrapper 不能免审采用。 |
| 商业算法 | 不排除 élastique 等授权 SDK | FL 官方明确使用 élastique。zplane 提供商业许可和 SDK；官方页面不公开可直接采用的报价，不擅自联系或承诺预算。 |
| Tempo 分析 | Beat This! 进入后台 beat/downbeat 质量候选，另比较许可合适的实现 | 不与 stretcher 混淆。Beat This! 的 Python/PyTorch 部署和 Rust 嵌入未验证，不能承诺开箱即用的原生 Auto-Warp。 |

这不是“库名叠满就完成引擎”的清单。完整引擎与模块组合两条路线需要以同一操作和声音基准比较，不能凭熟悉 Rust 提前淘汰成熟 C++，也不能为了少写代码接受不合适的工程模型。

Firewheel 只作为图调度候选。已通过 Context7 与固定提交交叉核对，其内置 sampler 的 `speed` 会改音高，`Streamed` 分支未完成。Creek 发布适配器依赖旧版 Symphonia，不能把最新版格式能力直接套上。两者的缺口不是产品限制，而是采用成本；可以替换组件或使用自定义节点，不能虚报开箱即用。

独立 Tracktion 探针固定 Engine `877e39c0fe9f1c3e4a9d836f5f338688250875d7` 与 JUCE `7ff644f65d7daa1428c34b9738ebb5c449dc9172`。后者当前是 JUCE 9，源码 [LICENSE.md](https://github.com/juce-framework/JUCE/blob/7ff644f65d7daa1428c34b9738ebb5c449dc9172/LICENSE.md) 明确 AGPLv3 或商业许可，不能套用旧版 JUCE GPLv3 结论。独立 Release 构建成功不代表 Tauri 集成、商业分发或播放验收通过。

## Browser 的工程建议

- 添加目录不复制整个素材库。目录发现、持久索引、搜索、波形和节拍分析分开，不把每次键入变成全库递归扫描。
- 先做查询代次和试听取消。快切时只有当前选择可发声，旧任务完成不能改变新选择。
- 扫描和分析在后台、有预算、可取消，不能抢占播放所需的磁盘和 CPU。缓存热度和文件压缩率必须进入负载测试。
- 未知、分析中、已就绪、离线、损坏不是一个 disabled 状态。只有同步试听尚未准备好时，仍应清楚显示原因和可用操作。
- Raw 原速定位、增量浏览、清楚的媒体依赖状态作为候选改进。它们不因 Live 目前受限就失去价值，也不因交互可做就跳过技术可行性验证。

## 媒体管理建议

Browser 目录注册、工程媒体收集、解码缓存是三个独立概念。推荐支持引用和收集，并让工程是否自包含可见；暂不擅定默认自动收集或默认引用。

工程媒体身份不能等于绝对路径。一个源可以被多 Clip 使用，播放实例保持独立读游标、循环状态与拉伸历史。可重建的峰值、分析和 PCM 代理可以共享，但不能把一个共享流播游标当所有实例的状态。

保存不应在复制尚未完成时谎称工程已经便携。缓存清除不应移除唯一原始素材。素材被移动、同名替换、修改和损坏时，需要避免自动把错误文件重新链接到全部 Clip。

## 真实播放建议

音频回调只处理已准备好的数据。目录、文件打开、解码、分析、重采样准备与退役对象回收不阻塞回调。播放时定位与循环以样本时间执行，不由 UI timer 或 Canvas 帧决定。

停止、定位和松键不能照旧调研的笼统规则“队列满就丢”。可合并的连续参数目标与不可丢失的状态转换需分开。控制层应在拥塞时提供有界、可观测的协议，不靠音频线程等待。

试听与编排必须使用一致的媒体窗口、时间映射、拉伸参数和延迟补偿。独立试听游标不代表独立实现另一套 DSP。

## 证明优于参考的验收

先确定同机器、同设备、同 buffer、同合法素材的比较方法，再从测量中定目标，不捏造当前 p95 或轨数。

1. 首次加入大库，索引期间浏览和播放并行。记录搜索尾延迟、界面卡顿、音频 deadline miss。
2. 上下键连续试听、快速改变搜索、折叠 Browser。验证最后选择获胜、取消不串音，量化等待和加载等待能区分。
3. 从同步试听拖到已有轨、新轨和非法目标。输出与试听一致，取消不残留半个导入事务。
4. 同源长文件在多个轨以不同偏移并播、各自循环。确认不竞争单个预读窗口，内存有界。
5. 鼓、人声、和弦与全混音在不同 BPM 比例播放，播放中变速和定位。比较起音、节拍漂移、音高、立体声与声音伪影。
6. 删除可重建缓存、断开源盘、移动已收集工程、替换同名文件后重开。验证素材身份、便携状态与恢复行为。
7. 两平台设备切换、声卡不可用、采样率与缓冲不受支持。错误不能伪装成成功，也不能破坏可保存的工程编辑。
