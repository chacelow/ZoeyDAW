# 原型范围与产品策略

## 当前范围

zoeydaw 是 Web-UI DAW。React 实现界面与交互，Tauri 承载桌面壳；Rust 音频核心、Mixer 和插件 host 是后续能力，不是当前已接通的功能。

当前有首页、单项目面板、Browser、编排时间线与组件画廊。工程编辑与本地快照通过 adapter 提供，默认后端只产生模拟时钟与视觉电平，没有音频输出，也不加载真实采样或插件。现有原子文件写入等桌面工具不等于工程已接入真实文件系统。

一个窗口同时持有一个项目视图；不恢复旧思维导图的多 Tab、Portal 或故障隔离架构。

## 迭代策略

按界面需求反推原生需求。先让交互可运行、状态和验收可观察，再落实 Rust 实现；不先铺音频引擎或假想长期架构。

可替换后端接口用于集中前端命令、预览与确认。它不代表真实解码、实时处理、设备路由、录音或插件 hosting 已完成，也不保证未来接入不需要调整契约。

兼容 Ableton Live `.als`，以及支持 CLAP/VST3，是产品方向，不是 Agent 可以自动扩展本轮任务的实现清单。具体支持范围由当次需求和真实验证决定。

## 范围判断

- 演示资源与模拟波形明确属于原型数据，不冒充本地文件或解码结果。
- 资源拖拽可演示 Ghost 与取消反馈；当前 Panel 禁用资源放置。
- 已有主题、语言和设置对话框保留，不用简化控件替换。
- 组件画廊用于验证共享组件的行为和规格，不与工程私有状态绑定。
- 调整目录、接口或工具链不自动授权提交、发布、部署或合并。

实现与状态契约见 [模块组织](architecture/modules.md)、[project adapter](../apps/web/src/pages/project/adapters/README.md)。
