# 产品范围与长期清单

## 当前范围

zoeydaw 是 gpuix 原生 DAW。React 写交互逻辑，gpuix 原生元素渲染，Rust（`crates/native`、`crates/engine`）提供原生能力与真实音频引擎。架构与验收见 [gpuix 架构](architecture/gpuix.md)。

旧 Web/Tauri 应用及共享 packages 已删除。保留迁移时确定的行为、状态、键盘、样式与产品规则，使用真实后端而不是 mock（用户 2026-10-14 13:21 UTC：Mock 到后面还要改一遍，不如直接用真实的）。删除旧实现不扩大功能范围，也不表示长期清单已全部实现。

一个窗口同时持有一个项目视图；不恢复旧思维导图的多工程 Tab、Portal 或故障隔离架构。工程内部的面板可以停靠、成组为 Tab（见长期清单“可停靠工作区”），这与多工程 Tab 是两回事。

## 范围判断

- 已接通的只说已接通的：设备 DSP、部分音频设置目前只是元数据，Browser 仍是演示目录、不能放置真实资源；报告里不把它们称为已完成。
- 已有主题、语言和设置对话框保留，不用简化控件替换。
- 组件画廊用于验证共享组件的行为和规格，不与工程私有状态绑定。
- 下面的长期清单是产品方向，不是 Agent 可以自动扩展本轮任务的实现清单；本轮之外的条目需要用户或协调者单独立项。
- 调整目录、接口或工具链不自动授权 push、发布、部署或合并到 `main`。

## 长期清单（用户 2026-10-12 版，2026-10-14 13:21 UTC 交给本轮）

大顺序：先界面，再引擎，最后插件和收尾。

**界面**

- 走带、素材浏览器、时间线、Session 网格、调音台、钢琴卷帘。
- 多语言：中英先行，所有文字外置成语言包。
- 主题设置：颜色/间距/字体写进配置文件，改了即时生效。
- 可停靠工作区（用户 2026-10-16，参考 [FlexLayout demo](https://caplin.github.io/FlexLayout/demos/v0.11/demo/index.html) 与 VS Code）：Browser、轨道/编排、Mixer、Clip 编辑器、设备链等做成可拖动、可停靠、可成组为 Tab、可最大化和隐藏的面板；顶部 Transport（播放、BPM、拍号等）和底部状态栏固定，不参与停靠。排期：统一配置 C 系列与 K1 命令注册表合入后开工，按下面四步：
  1. 布局模型：行/面板组/面板的树，JSON 序列化，按工程工作区保存；固定区域与可停靠区域分开。现有 `Group`/`Panel` 作为求解层复用，不另写一套尺寸算法；布局默认值走统一配置的 layout 来源。
  2. 面板注册表：每个面板按 id 注册（标题、图标、工厂、最小尺寸、能否关闭）。这一层就是以后扩展插入自己面板的接口，先只给内置面板用。
  3. 拖拽停靠：拖 Tab 或面板组到边缘/中心/Tab 条，显示落点预览；键盘可操作（移动到相邻组、最大化、关闭），走 K1 命令与 keymap；面板移动后组件状态保留。
  4. 浮动与弹出窗口：需要原生多窗口支持，最后做，单独评估。FlexLayout 本身依赖 DOM 和 CSS，不能在 gpuix 里直接用；借鉴它的 JSON 模型、工厂函数和属性继承设计。扩展 API（第三方面板）放在“插件”阶段，和 CLAP/VST3 一起设计。

**声音核心**

- 输入输出设置：选声卡、采样率、缓冲大小、输入输出通道。
- 播放引擎：播放、暂停、循环、变速，走带。
- 时间线编辑：clip 移动、修剪、分割、吸附。
- 波形显示：峰值预先算好，缩放不卡。
- 调音台：音量、声像、静音/独奏、发送、分组。
- 自动化：参数曲线录制和播放。

**录音与 MIDI**

- 录音：音频录进来、能监听、多 take。
- MIDI 输入：键盘演奏、控制器映射（MIDI Learn）。
- MIDI 编辑：钢琴卷帘里改音符。

**插件**

- 内置插件：EQ、压缩、延迟、混响，外加一个合成器、一个采样器。
- 第三方插件：先支持 CLAP，再支持 VST3。

**工程与文件**

- 工程保存/打开：自有格式，带版本号，自动保存防丢；兼容 Ableton Live `.als` 是方向。
- 导入导出：导出音频成品；MIDI 文件能进能出。

**进阶：人声与音高（引擎和拉伸就位后）**

- 音高分析：clip 打开自动检测音高、切出音符块，画在 clip 编辑器里。
- 逐音符修音：改单个音符的音高和时值（对标 Melodyne，先做单声部人声/乐器）。
- 多轨人声对齐：选一条主唱作参考，其他人声轨的时间和音高自动对齐（对标 Waves Sync Vx，原生集成、不用插件）。

**收尾**

- 性能：几百条轨道也不卡。
- ASIO：Windows 低延迟（需要 Steinberg 的 SDK）。
- 打包发布：安装包（发布本身仍需用户确认）。
