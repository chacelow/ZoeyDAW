# Project state ownership

`useProjectState.ts` binds React to one vanilla store created by `@zoeydaw/project-runtime/store`. Initial document, workspace and session factories live in `@zoeydaw/project-runtime/state`; the app supplies `DEFAULT_TRACK_HEIGHT`. `../adapters/index.ts` exposes app selectors and commands, and `context.ts` injects the native backend into one runtime. Each runtime owns its history, edits, confirmation checkpoints, registration stack and backend resources. Pure domain calculations live in `@zoeydaw/project-core`; display geometry stays in `../layout/`. See `../adapters/README.md` for lifecycle and persistence.

Application-wide control hover, warnings and mapping belong to `@/shared/control-interactions`. Each `ControlInteractionsProvider` owns one state instance; the component gallery uses an isolated provider/bridge. Project components consume this public environment rather than owning app-wide state in private project stores. They read project data through `useProjectState` and write through `projectActions`.

Canvas Scene is a rendering projection. Gesture previews are owned by the adapter and consumed through `getEffectiveDocument()`, then committed or cancelled with a session-scoped token. Controls, Canvas gestures, undo and redo share the backend state path. Playback head, Follow, meters and prototype MIDI recording consume the same accepted telemetry. Store subscribers must not introduce a second editable project or independent transport clock.

`session.editEpoch` identifies editing ownership even while no backend is acquired. Hydration, backend opening and last runtime release rotate it; controls and Canvas fence stale callbacks against that identity. Backend `sessionId` identifies engine protocol traffic only. Neither identity enters persisted snapshots. Constructing or importing the runtime creates no backend session.

`document.media` owns stable media identity and persisted locations. Clips refer to `sourceId`, never use paths as identity. Canvas Scene projects the same media array for labels and demo previews. `project-files/` owns the asynchronous file operation, current file binding, reported source issues and receipt bindings; it does not hold a second editable document. Save receipts preserve newer edits, and source location overrides apply only while the captured location and fingerprint still match. See the adapter persistence contract for publication and cancellation.

`document.patterns` owns shared MIDI notes and loop lengths. Pattern cards reference `patternId` and own only their independent placement and appearance. Editing shared notes uses the same document transaction and history as other authored edits. Canvas and backend consumers resolve references without owning editable copies.
